# نسخة سامو الجاهزة لـ Cloud Run — بدون قاعدة بيانات خارجية

تم تعديل المشروع ليحمل قاعدة SQLite المحلية وملفات البيانات داخل حزمة النشر نفسها، بدل الاعتماد على D1 أو Cloudflare Worker.

## ما تم إصلاحه
- تضمين `data/samo_warehouse.db` داخل `dist/data` أثناء البناء.
- تضمين `seed.json` و`backup_store.json` داخل `dist/data`.
- جعل الخادم يكتشف مجلد البيانات تلقائياً في Cloud Run.
- إصلاح خطأ SQL مكرر في تهيئة تفاصيل الطلبات عند إنشاء قاعدة جديدة.
- لا حاجة إلى `SQL_DB_NAME` أو رابط Cloudflare Worker لعرض بيانات المستودع.

## النشر
بعد رفع هذه النسخة إلى Google AI Studio / Cloud Run، نفّذ إعادة النشر.

إذا كانت خدمة Cloud Run تستخدم متغيرات البيئة، اترك `GEMINI_API_KEY` إذا كانت ميزة تحليل صور الأدوية مطلوبة. يمكن حذف `SQL_DB_NAME` لأنه لم يعد مطلوباً.

> ملاحظة: SQLite داخل Cloud Run تخزين محلي للحاوية وليس قاعدة بيانات خارجية دائمة. البيانات الابتدائية موجودة داخل المشروع، لكن التغييرات على SQLite قد لا تستمر بعد إنشاء Revision/حاوية جديدة. للبيانات المشتركة والدائمة بين أجهزة متعددة يلزم تخزين دائم خارجي.
